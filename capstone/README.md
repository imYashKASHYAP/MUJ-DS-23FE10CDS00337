**FeedbackLens** is an aspect-based customer feedback and review intelligence system powered by Google Gemini and a Python backend.

### Project Highlights
- **Domain:** Natural Language Processing (NLP) & Large Language Models (LLMs)
- **Model:** Google Gemini Flash-Lite (`gemini-3.1-flash-lite`)
- **Architecture:** Zero-dependency Python server with Vanilla HTML5/CSS3/JS Web UI
- **Key Modules:**
  - PII Masking Engine (`re`)
  - Strict JSON Schema & Anti-Hallucination Grounding Checker
  - SHA-256 Deduplication Cache
  - Deterministic Trend & Metric Aggregator
  - Interactive Browser Dashboard
